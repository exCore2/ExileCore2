ExileCore2 is a framework for making and launching quality of life and light automation utilities (called plugins). 

Plugins made by me are here https://github.com/exCore2/

Another list including select third party plugins https://excore2.github.io/PluginBrowser/plugins. The ingame plugin updater also uses this link to get the available plugin list

A bit on what this can do right now

* Map layout reveal (Radar)
* Monsters on the minimap, as far as the server allows (MinimapIcons)
* Highly customizable monster health bars (HealthBars)
* Ability to write scripts to customize many simple actions like using flasks, skills, it can also do simple graphics output like progress bars etc. to make your own weak auras if you are so inclined (ReAgent)
* Tracking where monsters are aiming/walking to avoid attacks (WhereAreYouGoing)
* Automated item pickup using custom rules (PickIt)
* Rule engine to highlight items in vendor inventories (NpcInvWithLinq)
* Dump to/from stash with optional filtering (HighlightedItems)

There is also a lot of plugins that simply need to be ported to PoE2 and of course you can create your own
